# 캠퍼스온 — Python RSS 대학 뉴스

Python 3.9 이상. API 키와 추가 패키지는 필요하지 않습니다.

새 RSS 수집 시 자동 분류 검사를 실행하고 `classification_monitor_report.json`에 신규/갱신 건수·무결성 오류·검토 후보를 기록합니다. 상세 범위는 `incoming_classification_review.md`를 참고하세요. 서버를 종료하거나 무료 호스팅이 절전 상태에 들어가면 수집·검사도 중단됩니다.

중복·링크·날짜·수집·엑셀 추가 점검은 `site_integrity_review.md`에 기록했습니다. 공통 제목만 같은 보도의 오통합을 방지하고 활동 유형이 다른 보도를 분리하며, 엑셀 파일명에도 한국 날짜를 사용합니다. 읽기 점검은 `python university-hub/integrity_audit.py --links`, 실행 중인 서버의 엑셀 대조는 `python university-hub/verify_live_exports.py`로 수행할 수 있습니다.

분류 v4 재점검: 정책 표현(서울대 10개), 기사 코너명과 대학 연합 표현, 해외 동명 대학을 국내 대학으로 오인하지 않도록 문맥을 검사합니다. 공식 대학 발행 소식의 대학명, 확인된 대학 부속병원의 별도 소재지, 공동캠퍼스, 국립 표기·약칭을 보완합니다. 참가자의 국적과 행사의 소재지를 구별하며 기사 구분은 제목을 우선합니다. 입시 키워드를 단순 부분 일치로 판단하지 않습니다. 점검 내역은 `classification_review.md`, 전체 변경 전후는 `classification_changes.json`에 있습니다. 서버 중지 후 `python university-hub/review_classification.py --apply`로 재분류를 저장할 수 있으며 옵션 없이 실행하면 읽기 점검만 합니다. 실행하면 점검 보고서는 최신 결과로 교체됩니다.

중복 처리 v2: 기존 저장 기사와 새 RSS 기사에 같은 사건 판별을 적용합니다. 대학 정식 명칭·약칭, 제목의 띄어쓰기·문장부호, 고유 장소·행사명과 주제어, 실제 RSS 요약을 비교합니다. 공통 고유명사와 다수 기사의 주제가 일치하면 표현이 다른 보도도 묶고, 실제 요약 정보량·제목 구체성·원문 링크 순으로 대표를 선택합니다. 서로 다른 대학·확인된 캠퍼스·숫자·모집/결과/취소 단계와 72시간을 넘는 보도는 구별합니다. 화면·기간별 건수·엑셀은 대표 기사만 사용하고 원본은 재검증을 위해 캐시에 보존합니다. RSS 요약이 없는 경우 제목에 근거하므로 의미상 중복을 완벽하게 판별하지는 못합니다. 점검: `python university-hub/audit_articles.py`, 회귀 검사: `python -m unittest discover -s university-hub -p "test_*.py"`.

## 수집

- 시작 시 수집 후 30분마다 갱신. Python 서버 실행 중에만 수집합니다.
- 브라우저는 15초마다 서버 상태와 기사 목록을 조회합니다.
- 기본 소스는 SBS 사회 RSS. 대학 관련 키워드가 있는 기사만 표시합니다.
- 제목, RSS 요약, 게시 시각, 출처, 원문 링크를 표시합니다. 전문은 수집하지 않습니다.
- 게시 시각으로 최신순 정렬하고 화면은 한국 시간으로 표시합니다. 날짜가 없으면 맨 뒤에 표시합니다.
- 같은 링크는 중복 제거하고 최근 5,000건을 .rss-cache.json에 보관합니다. 실패 시 기존 자료를 유지합니다.
- 예시 데이터는 실제 기사에 섞지 않습니다. RSS에 대학 기사가 없으면 0건일 수 있습니다.
- 지역은 rss_collector.py의 대학명 목록으로 추정합니다. 복수 캠퍼스는 복수 지역에 분류합니다. 미분류는 전체 지역 및 지역 미분류 선택 시 표시합니다. 전국 모든 대학을 포함하지는 않습니다.
- 소식 유형도 키워드 분류라 오분류가 있을 수 있습니다.

## 공공 대학 주소록 기반 지역 분류

university_addresses.json은 한국대학교육협의회의 전국대학및전문대학정보표준데이터 공개 다운로드 자료입니다.
출처: https://www.data.go.kr/data/15107736/standard.do
2026-10-27에 받은 자료는 주소 440건, 대학명 407개입니다. 원자료 기준일과 주소·홈페이지·본분교 정보도 보관합니다.
갱신: 작업 폴더에서 `python university-hub/sync_university_addresses.py` 실행 후 서버 재시작. API 키가 필요하지 않습니다.

기사 제목·RSS 요약에서 정식 대학명과 약칭을 찾고, 등록된 도로명주소의 시·도로 분류합니다. 기사 상세창에서 주소와 출처를 확인할 수 있습니다.
여러 소재지가 있는 대학은 캠퍼스가 명시되면 우선 적용하고, 특정할 수 없으면 주소록에 있는 복수 지역을 유지합니다.
주소록에 없는 기존 등록 대학은 수동 소재지 목록으로 보완하고 상세창에서 이를 구분합니다. 확인되지 않은 대학·외국 대학·일반 정책 기사는 임의로 지역을 배정하지 않습니다.
원자료의 누락·이전 주소·새 학교명 등으로 미분류나 오분류가 남을 수 있습니다. 새로운 기사마다 외부 검색엔진에 대학명을 전송하지 않고 내려받은 주소록에서 대조합니다.

캠퍼스 주소 확인: campus_addresses.py의 캠퍼스 약칭·도로명 연결과 대학 공식 자료 보완을 사용합니다. 같은 시·도의 캠퍼스도 개별 주소로 구분합니다. 캠퍼스가 명시되었으나 주소를 확인하지 못하면 본교로 대체하지 않고 지역 미분류로 둡니다. 기사 상세창에 캠퍼스명·주소·개별 출처 및 미특정 여부를 표시합니다. 현재 제목과 RSS 요약에 나타난 표기를 대상으로 하며 기사 전문에만 있는 캠퍼스는 확인하지 못할 수 있습니다.

기사의 명시 지역도 분류합니다: 제목과 RSS 요약에서 17개 시·도의 정식 명칭 및 주요 약칭을 인식해 대학 소재지와 함께 적용합니다. 상세창에서 제목/요약 중 어느 문구가 근거인지 표시합니다. 경기(경제·스포츠)는 지역 맥락이 명확할 때만 처리하고 경기도 광주시는 광주광역시와 구분합니다. 기사 전문은 수집하지 않으므로 전문에만 있는 지역은 반영되지 않습니다.

해외 지역 필터: 제목·RSS 요약에 명시된 주요 해외 국가명, 외국 대학명, 해외·외국 관련 표기로 분류합니다. 국내 대학의 해외 교류 기사는 국내 시·도와 해외에 함께 표시합니다. 일본어·중국어처럼 국가명이 포함된 강좌명만으로 분류하지 않습니다. 사전에 없는 국가·대학은 미분류로 남을 수 있습니다.

엑셀 다운로드: 목록 상단 버튼으로 현재 지역·유형·검색·관심 소식 필터에 해당하는 모든 기사를 현재 정렬대로 .xlsx로 저장합니다. 페이지의 더 보기 여부와 관계없이 전체 필터 결과를 포함합니다. 대학명, 한국 시간 보도일자, 시·도, 구분, 기사명, 원문 URL, 기사 보기 URL, 언론사, 캠퍼스 주소, 수집 경로를 제공합니다. 구글 경유 기사에 원문 주소가 제공되지 않으면 원문 URL은 비워두고 기사 보기 URL에 경유 링크를 넣습니다. 추가 패키지는 필요하지 않습니다.

엑셀 요약 통계: 첫 시트에 대학명 표기별 × 기사 구분별 건수표, 총계, 구분별 건수·비율표, 편집 가능한 가로 막대그래프를 포함합니다. 통계는 현재 다운로드에 포함된 기사만 대상으로 다운로드 시점에 계산합니다. 복수 대학 기사는 대학명 묶음을 한 행으로 집계해 중복 합산을 방지합니다. 사진과 동일한 지원사업 분류 대신 현재 사이트의 기사 유형을 사용합니다. 기사 원문 데이터와 URL 하이퍼링크는 대학 기사 시트에서 확인할 수 있습니다.

URL 열 통합: 기사 목록의 링크는 기사 URL 한 열로 제공합니다. 확보된 original_url을 우선 사용하고 없으면 수집된 기사 링크를 사용합니다. URL 셀은 클릭 가능한 하이퍼링크입니다.

기간 필터: 전체 기간·오늘·최근 7일·최근 30일·직접 선택을 제공합니다. 최근 7일/30일은 한국 시간 기준 오늘 포함 달력 일수입니다. 직접 선택은 시작일과 종료일을 포함하며, 날짜 누락/역전이면 안내하고 내보내기를 비활성화합니다. 게시일이 없는 기사는 전체 기간에서만 표시합니다. 기간 필터는 목록과 엑셀·요약 통계에 함께 적용됩니다. RSS 수집 기간 자체를 늘리거나 과거 기사를 추가 수집하는 기능은 아닙니다. 날짜 경계 테스트: Node.js가 있는 경우 node university-hub/test_period.cjs.

해외 분류 문맥 보완: 요약에서만 국가명이 등장한 경우에는 제목에 교류·협약·공동연구·방문·유학 등 국제 활동 문맥이 있을 때만 해외 근거로 사용합니다. 국내 대학 기사에서 해외 사례를 참고·비교한 배경 설명은 제외합니다. 해외 대학 자체가 주제인 제목이나 실제 국제 교류는 해외 분류를 유지합니다. 규칙 기반이므로 문맥이 복잡한 기사에서는 오분류가 남을 수 있습니다.

국내 소재지 문맥 보완: 주관 대학·캠퍼스/제목의 지역을 우선하고, RSS 요약의 추가 지역은 명확한 행사 개최 장소나 공동 주관기관이 확인될 때 적용합니다. 참가자 거주지·출신·단순 비교 사례의 지역은 제외합니다. 실제 다른 지역에서 개최하는 행사는 해당 지역과 주관 대학 소재지를 함께 유지합니다.
